This is the code for the paper "Interpretable decision trees to predict solution fitness" by Catalano et al, and for "Evaluating a Novel Explainability Method for Metaheuristics via a
User Study" also by Catalano et al.

## If you're here for the Interpretable decision trees paper:
* The code in main is to produce the experimental data, which can then be processed by VarianceDecisionTree\process_data\accuracy_by_settings.ipynb


## If you're here for the user study paper:
* UserStudy/questionnaire_materials.zip has the pdfs explaining the optimisation problem, the questionnaire and visualisations
* UserStudy/problems_and_explanations_script.py is what generated the explanations (although the visualisations were made manually...)
* the data gathered is in UserStudy/data/answers_04_02.tsv. It was analysed using the files in parse_answers.ipynb
